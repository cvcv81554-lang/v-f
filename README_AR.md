# تطبيق vkte لشاشة TCL (Android TV / Google TV)

هذا مشروع تطبيق Android صغير (غلاف WebView) يفتح موقعك على Cloudflare بشاشة كاملة، ويفعّل **وضع التلفاز** تلقائيًا (تنقل بالأسهم + OK + رجوع).
أي تحديث تنشره على Cloudflare يصل التلفاز تلقائيًا دون إعادة بناء الـAPK.

> يعمل على شاشات TCL التي نظامها **Google TV أو Android TV** (الأغلب في السعودية). لا يعمل على **Roku TV** (يستحيل تثبيت APK عليه) — استخدم البث (Cast) من الجوال.

## 1) بناء ملف APK (مرة واحدة، بدون برامج)
1. أنشئ حسابًا على github.com، ثم **New repository** (اجعله Private).
2. ارفع كل محتويات هذا المجلد للمستودع (Add file → Upload files).
   - إن لم يظهر مجلد `.github` بعد الرفع: اذهب Add file → Create new file، اكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف `github-workflow/build-apk.yml`.
3. افتح تبويب **Actions** → **Build Android TV APK** → **Run workflow** → ضع رابط موقعك (مثل `https://my-app.pages.dev/`) → Run.
4. بعد دقيقتين تقريبًا ادخل على العملية الناجحة ونزّل **vkte-tv-apk** (zip) ثم فكّه، وفيه `vkte-tv.apk`.

## 2) تثبيته على التلفاز (اختر طريقة)
**أ) أسهلها: تطبيق Downloader**
1. ثبّت **Downloader** من متجر Google Play على التلفاز.
2. أعدادات التلفاز → التطبيقات → الأمان والقيود → **تثبيت تطبيقات غير معروفة** → فعّلها لـDownloader.
3. ضع الملف `vkte-tv.apk` داخل مجلد موقعك قبل النشر على Cloudflare (بجانب index.html)، وبعد النشر افتح Downloader وأدخل `https://my-app.pages.dev/vkte-tv.apk` ثم Install.

**ب) فلاشة USB:** انسخ الـAPK لفلاشة، وافتحه بتطبيق مدير ملفات (مثل File Commander) على التلفاز.

**ج) من الكمبيوتر (ADB):** فعّل خيارات المطوّر (اضغط على «إصدار البناء» 7 مرات) ثم تصحيح USB/الشبكة، ثم: `adb connect IP_التلفاز` ثم `adb install vkte-tv.apk`.

## 3) نقل بياناتك إلى التلفاز
بيانات التطبيق تُحفظ لكل جهاز. من الجوال: الإعدادات ← النسخ السحابي ← رفع. على التلفاز: الإعدادات ← النسخ السحابي ← أدخل رابط الـWorker وكلمة السر ← استرجاع.
(التصدير كملف JSON لا يعمل داخل التلفاز؛ استخدم الجوال للنسخ الاحتياطي.)

## الأزرار على الريموت
- الأسهم: تنقل بين البطاقات والأزرار · **OK**: فتح · **رجوع**: إغلاق النافذة ثم الخروج
- زر **Menu/القائمة** (إن وُجد في ريموتك): قفز سريع بين المحتوى والشريط السفلي. أو انزل بالسهم حتى آخر صف فتصل للشريط.

## ملاحظات
- ستريميو: زر ▶ في التطبيق يفتح بحثه إن كان مثبتًا على التلفاز (اختر «ستريميو» من الإعدادات). أما نوفيو فلا يدعم فتح بحث برابط، فيُنسخ الاسم فقط. أي رابط `nuvio://` يُحجب عمدًا لأنه يثبّت إضافات بلا تأكيد.
- إن كان نظام WebView في التلفاز قديمًا حدّث «Android System WebView» من متجر Google Play.
- الـAPK من نوع debug (موقّع بمفتاح تجريبي) وهذا كافٍ للتثبيت اليدوي. لو أعدت بناءه لاحقًا بمفتاح مختلف فاحذف التطبيق القديم أولًا.
- لم أستطع بناء الـAPK داخل بيئتي (لا يوجد Android SDK ولا إنترنت)، لذا مشروع البناء لم يُجرَّب فعليًا؛ إن فشلت خطوة في Actions أرسل لي نص الخطأ.
